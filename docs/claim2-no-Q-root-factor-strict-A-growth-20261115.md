The new root-factor equivalence from #1227 shows that in a
GENUINE full target free amalgam, a selected-Q full-native source
replacement with entire Q B-inactive and complete Q root in
the FULL target seam is A-neutral **iff** the exact actual
weak target values of Q arise from an EHN homomorphism-embedding
Q.str → X through the full target-root embedding.

This module turns it into a precise positive-support obstruction.

1. fullNativeRootedPiece_noEHNinX_forces_privateA:
   if NO EHN weak homomorphism-embedding Q.str → X exists
   (a genuine structural assumption to check against
   irreducible source tests), any actual selected-Q source
   embedding with B-inactive all Q and seam-valued rooted Q
   MUST contain a private Q-nonroot SOURCE vertex mapped
   to A-exclusive target.
2. geometricSelectedQ_noEHNintoX_strict_AactiveSourceGrowth:
   if the original removed selected component was A-free
   and the old/new E complement target maps agree exactly,
   the merged source-cost equation
       new A-source count = old A-source count
                              + new private-Q A-source count
   yields **strict A-SOURCE support increase**.

This is a genuine warning for the 2019 Claim 2 induction:
if the actual selected forbidden Q cannot weakly EHN-map into
the full common root, its B-to-A flip provably cannot preserve
the global original A-support minimum of the old witness.
This does not claim ALL selected Q have that property or
exclude alternative descending potentials / source state
normalizations. No source-target quotient or weak map
injectivity is assumed or asserted.

The separate weighted potential proof #1208 gives the
exact numerical alternative condition:
   weight * A_private_Q < B_removed_old_component.
This note does NOT assert any weight uniformly succeeds.
