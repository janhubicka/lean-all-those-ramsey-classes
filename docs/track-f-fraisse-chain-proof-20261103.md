# Track F: a source-faithful Fraïssé chain proof for full functional lifts

**3 November 2026 — English proof and formalization boundary.**

This document gives the finite-extension / direct-limit proof that can be
formalized from the existing **conditional** Section 3 finite-age interface.
It is deliberately separated from the frozen numbered manuscript and from
an unproved claim that Mathlib already supplies an existence theorem.

## Precise theorem to formalize

Let `L` be the original finite native relation/partial-function
signature, possibly allowing nullaries. Let `F` be a regular family
of nonempty connected finite forbidden sources. Write `K` for the
native `Forb_EHN(F)` class, and `K*` for the ORIGINAL **root-injective**
maximal global-trace finite age, with full structural embeddings.
Assume:

1. **Full native JEP**, in particular compatibility of any old
   nullary data carried by two `K`-members.
2. **Full original shadow-free amalgamation**:
   `GlobalCanonicalShadowFreeAmalgamation F K`.
   This is **NOT** proved for arbitrary reducible families from the
   printed image-closure/regularity hypotheses. It is proved for
   irreducible forbidden sources.

Under these hypotheses, the already verified finite-age interface
supplies heredity, genuine full strong AP, finite age members,
countable full-isomorphism representatives, and a member on the
empty carrier. The original lifted signature is countable by
regularity; this holds even when `F` is infinite and the new
piece widths are unbounded.

**Claim for future Lean formalization:** There is a countable full
functional structure `M*` which is ultrahomogeneous for finite
FULL substructures and whose finite full-substructure age is
exactly `K*`. This is a standard Fraïssé argument adapted to
complete set-valued function fibres. It is **not yet a proved Lean
declaration** and is not the full 2019 Ramsey theorem.

## Step 1. Enumerate finite isomorphism types and extension diagrams

Merged Track F #798 constructs a countable type
`Σ n, {Z : Structure (globalFunctionalPieceLanguage F) (Fin n) //
IsGlobalFiniteMaximalTrace F K Z}` containing a FULL surjective
isomorphism representative of every finite age member.
Merged #787 proves that for any fixed finite carrier `Fin n`
the set of such members is finite, even for infinitely many added
global piece symbols, provided the old symbol types are finite.
Between any two finite representatives, the type of FULL
embeddings is finite (already provided by
`StructuralRamsey.Structure.Embedding`).

Hence the type of finite extension diagrams
`(P_i, Q_i, i_i : P_i ↪ Q_i)`, up to chosen labelled representatives,
is countable. Fix an enumeration which visits each diagram
infinitely often. To control universality separately, also
enumerate the individual finite representative types `Q_i`.
The construction does NOT presume that `P_i` or `Q_i`
is irreducible, generated by a single vertex, or has one-point
closed extension.

## Step 2. The finite saturation lemma

Fix `X, B ∈ K*`, a FULL root embedding `i : A ↪ B`,
and a finite list of FULL embeddings `f_j : A ↪ X`.
An actual strong amalgam of `X` and `B` over `A`,
along `f_0` and `i`, yields an age member `X'`
and full embeddings `X ↪ X'` and `B ↪ X'` agreeing
exactly on the prescribed root. Repeat this for each remaining
`f_j`, composing earlier full embeddings into each new target.
No previously met request is destroyed because the entire earlier
age member embeds FULLY into each subsequent one.

Crucially, the actual strong-AP interface includes an equality
for **precisely the prescribed intersection**; the commutative
root equation follows by its forward implication. We never
construct a weak source quotient or replace a function-closed
root by an arbitrary generated hull.

Since the `A`- and `X`-carriers are finite, their full
embedding type `Embedding A X` is finite. Taking the list of
all such embeddings proves **one-step saturation for every
copy of A in X simultaneously**. This theorem is proposed in
Track F PR #825,
`GlobalFiniteFraisseExtensionScheduler.lean` (full CI required).
It has no infinite-limit or shadow-avoidance-completion conclusion.

## Step 3. Build a cofinal chain

Recursively construct finite age members `X_n` and FULL
embeddings `j_n : X_n ↪ X_{n+1}`:

* Start with the genuine empty-carrier maximal trace supplied by #778.
  The chosen nullary tables of the next structures cannot be arbitrarily
  incompatible: the FULL native JEP hypothesis and original JEP
  transfer govern this compatibility.
* First jointly embed `X_n` and the n-th enumerated age representative.
  This ensures every age object eventually embeds into the chain.
* For every extension diagram with index at most `n`, apply the finite
  saturation lemma to **all full root copies in the current finite stage**,
  sequentially. There are finitely many diagrams at each stage,
  and every operation produces another genuine finite `K*` member.
* The resulting final stage is `X_{n+1}` with the composite FULL
  embedding of `X_n`. Retain all witnesses in the recursive data.

By making the extension-diagram enumeration recurrent, every finite
diagram is eventually handled **after** any chosen finite root copy
appears in the chain. The construction uses only finite JEP and
strong AP, not an already-existing limit.

## Step 4. Form a direct limit preserving COMPLETE functions

Take the direct limit `M*` of the chain of finite carriers and
injective maps. It can be represented as a quotient of
`Σ n, X_n.Carrier` by eventual equality under the transition maps.
Every vertex of `M*` comes from a finite stage and the canonical
maps `u_n : X_n ↪ M*` are injective.

Define each relation tuple to hold precisely when it holds at a
common stage containing all its coordinates. Define a native
function-value incidence `y ∈ F^{M*}(x̄)` in exactly the same way,
using a common stage containing **both the inputs and output**.
These definitions are independent of the stage:
for any FULL transition embedding `e`, one has

`e '' (F^{X_n}(x̄)) = F^{X_{n+1}}(e(x̄))`.

This is equality of the **entire** output sets, not just positive
incidence preservation. Therefore no new function output over an
old stage input tuple can appear later. It follows that every
`u_n` reflects all old and added relations and maps each whole
set-valued function fibre exactly onto the corresponding fibre
of `M*`: each `u_n` is a genuine FULL functional embedding.
This includes nullary functions and input tuples with repeated
coordinates. Any finite vertex set lies inside some finite
full-closed stage, so its generated native closure is finite.

The required Lean work is a generic direct-limit library for
`StructuralRamsey.Structure`, not a bare induced graph colimit:
a relationalized `L.graph` embedding alone does not guarantee
the necessary full function-fibre equality without function-closed
image data.

## Step 5. Age, extension property and homogeneity

For every finite `A∈K*`, Step 3 and the full direct-limit maps
give a full embedding `A ↪ M*`. Conversely, if a finite
`A` admits a FULL embedding into `M*`, its finite image is
contained in the image of some stage `X_n`. The direct-limit
map is full, so this embedding factors as a FULL embedding into
`X_n`; heredity gives `A∈K*`. Thus the finite FULL age of
`M*` is precisely `K*`.

For a finite extension `i:P↪Q` in `K*` and a full
embedding `f:P↪M*`, the finite source image lies in some
stage and `f` factors FULLY through that stage. At a
later stage where the diagram `i` is scheduled, its finite
saturation step produces `Q↪X_m↪M*` extending `f`.
This proves the exact finite extension property.

For a full isomorphism between finite, closed substructures of
`M*`, alternate the extension property in the two directions,
enlarging each finite closed domain to include the next vertex
in a fixed countable enumeration. Generated closures of finite
subsets stay finite by Step 4, so the back-and-forth constructs
a full automorphism of `M*`. This is ultrahomogeneity.

## Step 6. The omega-categorical claim needs RELATIONAL shadows

When the original language is finite relational (no old function
symbols), the expanded structure is also relational, though its
language may contain infinitely many new piece-class symbols.
Every finite vertex subset is then a full substructure, and
merged #787 gives **finitely many** possible expanded induced
structures on an n-element carrier. Homogeneity therefore yields
finitely many automorphism orbits on n-tuples, accounting also for
repeated coordinates. With the countable expanded language (#804),
the usual oligomorphicity criterion gives omega-categoricity
of the ultrahomogeneous expansion; relating that to the native
shadow requires an explicit reduct argument.

For languages with native functions, **do not** infer
omega-categoricity from fixed-carrier table finiteness: the
closure of one vertex in the limit can have arbitrarily large
finite size (e.g. cycles of a unary function). This explains the
finite **relational** hypothesis in the paper's
omega-categoricity conclusion.

Existential completeness and universality of the native shadow
within the correct `Forb_EHN(F)` setting are separate model-theoretic
claims. A bare age/homogeneity theorem does not silently establish
them, and the full Ramsey property needs still further
local-completion / copy-transport arguments.

## Adversarial checklist for the Lean implementation

- **Non-vacuity:** full JEP with nullary data is an explicit hypothesis,
  not a consequence of regularity. The actual JEP-iff-native-JEP
  theorem and nullary obstruction are merged as #807; TODO ATRC-073.
- **Shadow avoidance:** the original reducible-source Claim 2 and
  `GlobalCanonicalShadowFreeAmalgamation` remain unproved. The
  one-stage scheduler uses the age-input record that retains this
  hypothesis; it cannot repair it.
- **Fullness:** arbitrary induced relational substructures of the
  graph language need not decode to full function-closed structures.
  Full native embeddings and their complete function fibres must be
  preserved throughout the direct limit.
- **Representatives and embeddings:** the enumeration must be
  cofinal in full isomorphism types and in ALL finite extension
  diagrams; the finite type of root embeddings is not replaced by
  an unstated finite-class bound on witness sizes.
- **Universality:** add JEP requests for age objects separately;
  extension requests over a nonempty root do not by themselves force
  all types to occur if no corresponding root embedding exists.
- **Relational omega-categoricity:** only assert finite tuple-orbit
  counts once closure of arbitrary finite sets is trivial (the
  original relational case), or provide separate uniform bounds
  on generated closure types for functions.
