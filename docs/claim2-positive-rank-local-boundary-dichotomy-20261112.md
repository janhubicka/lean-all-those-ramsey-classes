on injection of the source weak map over the **ENTIRE preimage S**

`claim2_positiveRank_actualSuccessor_or_smallerRoot_of_activeBoundaryInjective`

requirement:

For every actual B-exclusive SOURCE vertex x in the current
genuine positive-width old outer geometric piece P, the weak
target map f is injective on the WHOLE generated functional
boundary `Cl(N(C_S(x)))` of the S-avoiding x-component.

Assume a finite connected genuine forbidden full-native
source, common full original canonical lift, genuine target
free amalgam, a real A-exclusive source anchor inside P,
positive B-exclusive SOURCE vertex count in P, and old
outer ordered root inside the common seam. Then exactly
one of the two typed alternatives is returned:

1. ONE actual SAME-selected-Q forbidden source, actual new
   geometric outer minimal separator, unchanged old ordered
   target-root coordinates and global canonical symbol,
   STRICT reduction in B-only SOURCE support INSIDE,
   exact SOURCE support preservation outside for ALL
   target subsets, and an actual retained A-only SOURCE
   anchor inside the new outer piece with the SAME target;
2. A real strictly smaller POSITIVE-width native closed
   separator root inside the selected generated B-boundary,
   with the exact opposite A-component generated-boundary
   equality. Its selected component might be MIXED and
   cannot be treated as a valid B-only flip.

The source component selector and opposite boundary dichotomy
never needed full S-injectivity. The only place it was used
in #1086 was restricting S-injectivity to the selected T
before the partner flip. The new theorem uses local
injection directly. **There is no third full-seam collision
alternative.**
