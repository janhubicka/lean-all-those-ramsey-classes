# Track C: zero local B rank gives an actual strict A-source flip

14 November 2026. Independent draft Lean source module based on
currently merged main, without altering the frozen original 2019
manuscript.

An original finite F-forbidden native Source with weak EHN map
f to a genuine full target free amalgam has actual geometric
minimal-closed-separator piece P with full ordered root in
the preimage of the target full common seam. Assume the
literal SOURCE-cardinal count of B-exclusive vertices inside
P is zero.

1. Under Finite V, if any component source vertex had
   image in the B-exclusive target part, that real vertex
   would witness a nonempty subtype and therefore positive
   Nat.card, contradicting exact zero. This is the named
   `claim2_zeroBSourceRank_selectedComponent_noRight`.
   No injectivity of f or distinct-image count is assumed.

2. `claim2_zeroBSourceRank_actualGeometricPiece_factorsLeft`
   obtains an actual native EHN weak factorization of P's
   full functional graph into the FULL Left target witness.

3. If P's ordered target root images are injective and
   P's selected component contains a real A-exclusive
   SOURCE vertex, the verified full global common-canonical
   lift source-flip mechanism produces a REAL new F-source
   and EHN map to the SAME full target amalgam with a
   STRICTLY smaller total A-exclusive SOURCE support.
   The concrete theorem is
   `claim2_zeroBSourceRank_Aanchor_actualStrictAFlip`.

4. Therefore at a witness GLOBAL-minimal in total original
   A-exclusive SOURCE count over all eligible F-source maps
   to the same target, this zero-B local state is impossible.
   When the old root has width one, target-root injectivity
   is automatic, without assuming injection on all target
   common-seam preimages. Two terminal contradiction theorems
   establish these facts.

CRITICAL SCOPE: this discharges the terminal A-clearing
argument only for an original A-support-minimizing witness
(or one whose global A-minimality is otherwise known), with
a genuine source geometric piece of positive ordered root
width and a real A-exclusive selected-component source anchor.
It does NOT prove that a succession of B-to-A rank-decreasing
flips preserves original A-support minimality. The iteration
gap is real: replacing B-only source vertices with an
A-side selected pattern may INCREASE total A-source support,
and generic canonical-lift equivalence alone does not
control this quantity.

Likewise initial normalisation, higher-width split-root
capture and the general 2019 strong-amalgamation conclusion
are NOT proved here.
