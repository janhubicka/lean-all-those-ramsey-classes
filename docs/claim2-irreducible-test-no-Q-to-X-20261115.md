The EHN weak homomorphism-embedding condition is STRONGER than an
arbitrary weak source homomorphism: for every genuine FULL
irreducible source test Test↪Piece, the restriction of the
weak map has to agree with some actual FULL embedding Test↪X.

If Test and the complete common-root source carrier X are
FINITE and Nat.card Test > Nat.card UX, this is impossible.
Therefore NO EHN weak map Piece→X can exist, even when
Piece itself is reducible and its other source vertices
could be identified under a global weak map.

Two new theorems:
* weakEHN_irreducibleFullTest_card_le_target;
* weakEHN_no_map_into_smaller_commonRoot_of_fullTest.

These make the explicit no-EHN(Q→X) hypothesis in the new
Track C structural A-neutrality obstruction (#1229, stacked
on #1227) CHECKABLE by a concrete native finite source test.

Important: no claim is made that every selected geometric
forbidden Q contains a test of cardinality larger than X;
the necessary hypothesis must be established for the actual
rooted Q or refuted by its own EHN factorization. Also no
source map injectivity is asserted globally, only the test
embedding guaranteed by the exact EHN definition.

In simple graphs, an edge test of two vertices cannot EHN-map
into a singleton common root, although a reducible source
without such a full test might still collapse. This is only
an illustrative irreducible-test capacity obstruction, not
a counterexample to the entire 2019 theorem.
